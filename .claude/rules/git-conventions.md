# Git 規約

## コミットメッセージ

**フォーマット**: `<絵文字> <動詞で始まる簡潔な英語説明>`（例: `✨ Add user authentication endpoint`）

絵文字レジェンド（複数該当時は左が優先）:
`✨`新機能 `🐛`バグ修正 `♻️`リファクタ `📝`ドキュメント `🎨`UI/スタイル `⚡`パフォーマンス `🔧`設定 `✅`テスト `🗑️`不要コード削除

判定条件の詳細・コミット生成・PR 作成は `git-workflow` skill を参照。

## コミット粒度

1 コミット = 1 論理変更。実装コード + 対応テスト + 設定登録は同一コミット可。

## ブランチ運用

コード変更は `master` から作成した作業ブランチ `<prefix>/<Issue 番号>-<題>`（例: `chore/3-issue-workflow`）で行う（命名規則・作成手順は `git-workflow` skill、完了条件は `definition-of-done.md` を参照）。

**`master` 直コミット可の例外:** タイポ・1行設定変更、`AGENTS.md`/`docs/` のみのドキュメント更新。

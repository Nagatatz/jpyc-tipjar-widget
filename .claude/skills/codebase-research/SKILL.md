# コードベース調査スキル

> 公式バンドル skill の `/deep-research` は **Web 検索**をファンアウトして出典付きレポートを作るもの。
> 本スキルは **このリポジトリのコード**を対象とする。調査対象が外部情報なら `/deep-research` を使う。

## タスク

$ARGUMENTS について調査し、次の点に答えられる状態にする。調べる順序は問わない。キーワード検索では同義語・関連語も当たる（命名が揃っていない箇所を拾うため）。

- **関連ファイル**: コア実装 / 周辺（利用箇所）/ テストの区別と、それぞれの役割
- **設計意図と期待される挙動**: コア実装から読み取れる意図と、テストが前提にしている挙動
- **依存関係**: 上流（このトピックが依存する基盤コンポーネント）と下流（このトピックを利用する箇所）
- **パターンと落とし穴**: プロジェクト固有の規約（命名 / エラーハンドリング / 抽象化レベル）、エッジケース処理の有無、TODO / FIXME / 技術的負債のマーカー

## 出力フォーマット

以下の構造で要約をメイン会話に返す（詳細な分析結果はサブエージェント側に留める）:

```markdown
## 全体像
1-2 段落で要約

## 主要コンポーネント
- `path/to/file.ext`: 役割と責務（1 行）
- ...

## パターン / 規約
- 命名: ...
- エラーハンドリング: ...
- ...

## 注意点
- バグの匂い / TODO / 技術的負債（ファイル:行番号付き）
```

## 起動例

- `/codebase-research authentication system`
- `/codebase-research how database transactions are handled`

# トークン最適化

## モデル選択

| モデル | 使う作業 |
|---|---|
| Haiku | ファイル検索・パターン照合、ドキュメント・コメント作成、typo / import 追加などの単純編集、フォーマット確認、定型ボイラープレート |
| Sonnet（既定） | 複数ファイルの実装、コード / PR レビュー、バグ修正・デバッグ、テスト作成、リファクタリング |
| Opus | アーキテクチャ設計・技術選定、セキュリティ分析、複数システムにまたがるデバッグ、性能最適化の設計、大規模リファクタリングの計画 |

## コンテキスト節約

- Glob / Grep で絞ってから、必要なファイルだけ Read する。
- 独立したタスクは `.claude/agents/` のエージェントに委譲する（例: 検索は `quick-search`）。

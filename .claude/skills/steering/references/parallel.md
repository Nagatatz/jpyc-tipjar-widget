# 並列実装（複数機能を同時に）

バッチブランチを中間ブランチにし、全機能をマージしてからデフォルトブランチ（`master`）へ入れる。

```text
master
 └── feature/<バッチ名>        ← 計画・マージ用
      ├── worktree-<機能名1>
      └── worktree-<機能名2>
```

1. `master` から `feature/<バッチ名>` を作る。
2. バッチブランチ上でステアリングを作成・承認する。
3. 各ウィンドウで `claude --worktree <機能名>` を実行し、実装する。共有ドキュメントはこの段階では更新しない。
4. 全機能ブランチをバッチブランチに順にマージし、毎回ビルドを確認する。
5. 共有ドキュメントをまとめて更新する。
6. バッチブランチを `master` にマージして削除する。worktree の削除は `worktree-safety` skill の順序に従う。

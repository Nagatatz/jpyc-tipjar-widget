# add-rule

1. **内容を特定**: 直前の会話から、ルール化する内容（規約・プロセス・命名など）を抜き出す。既存ルールと矛盾するならユーザーに確認する。
2. **配置先を決める**: `ls .claude/rules/` で既存ファイルを読み、追記先があればそこへ。無ければ内容を表すケバブケース名で新規作成（例: `error-handling.md`）。
3. **書く**（日本語、既存ファイルの文体に合わせる）:
   ```markdown
   ## <見出し>

   **以下は強制的な行動指示であり、例外なく従うこと。**   ← 本当に強制が必要なときだけ。軽い推奨は「〜すること」

   <ルール本文>

   **例外:** <あれば>
   ```
   新規ファイルは `# <タイトル>` から始める。
4. **CLAUDE.md に反映**: 新規ファイルなら CLAUDE.md の `@import` 一覧に `@.claude/rules/<ファイル名>.md` の行を追加する。CLAUDE.md の記述に影響するならそこも直す。
5. **確認**: 追加・変更内容を提示し、承認後に保存する。
